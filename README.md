# Tony's English Shadowing (토니의 영어 쉐도잉 도서관)

유튜브 기반 영어 쉐도잉 & 리스닝 전용 라이브러리입니다.
엄선된 유튜브 영어 영상의 정확한 대본, 한 줄 단위 직역, 원어민 발음 반복 청취, 어순감각 체득 및 행맨 퀴즈를 제공합니다.

## 주요 기능
- **전체 콘텐츠**: 난이도(Level 1~5)별 카드 탐색 및 검색
- **채널별 탐색**: 영어 학습 채널별 시리즈 모아보기
- **화자별 탐색**: Steve Jobs 등 명연설·명강사의 고유 쉐도잉 콘텐츠 탐색
- **개별 쉐도잉 룸**:
  - 문장별 분할 청취 & TTS 속도 조절
  - 단어 카드 (영영 풀이, 직역, 예문)
  - 핵심 문장 행맨 퀴즈
  - 전체 스크립트 직역 대조

## 라이선스 & 출처
본 서비스의 영상 및 자막 저작권은 각 원작성자(YouTube 채널)에 있으며, 교육 및 학습 목적으로 제공됩니다.
